# Competitive Programming and Contests (2025-2026): Exercises and Hands-On

Exercises for the course [Competitive Programming and Contests](https://pages.di.unipi.it/rossano/competitive/) (University of Pisa, Prof. Rossano Venturini).

All solutions are implemented in **Rust**.

⚠️ The page of the course references problems to submit on GeeksForGeeks, which, however, does not allow for submissions in Rust. I have substituted them with equivalent problems from [cses.fi](https://cses.fi/problemset) and LeetCode.
